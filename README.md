# ImageText - утилита по считыванию текста с изображения

ImageText — утилита, которая принимает изображение и распознаёт на нём текст. Программа поддерживает русский и английский языки, а также определяет уверенность модели в каждом распознанном фрагменте.

## Возможности

- Загружать изображение с диска и приводить его к формату, пригодному для распознавания.
- Распознавать текст на изображении с помощью EasyOCR.
- Выводить найденные текстовые блоки и уверенность модели для каждого из них.

## Требования

- Python 3.13.
- Poetry 2.x
- Make (для удобных команд)

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/KolkiRik/fpl-ImageText.git
   ```
2. Установите необходимые зависимости (poetry сам создаст окружение):
   ```bash
   make install
   ```
   Или напрямую:
   ```bash
   poetry install
   ```

## Запуск программы (тестовой версии)
   ```bash
   make run
   ```
   Или напрямую:
   ```bash
   poetry run python src/main.py
   ```
